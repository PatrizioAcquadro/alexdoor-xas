# Phase 2 Report — Scripted Baseline and Deterministic Data Engine

**Status: complete** (2026-07-02). One phase, four internal milestones (2.1–2.4).
Per-run manifests live in `outputs/<experiment>/<run_id>/report.md`; this file is
the durable summary of the verified reference run.

## Scene (2.1)

The isolated single-door fixture (`outputs/door_task/door_task.usda`, generated by
`assets/door_task.py` from `~/Desktop/CombinedScene/Door.usd`) was kept. One real
blocker surfaced the moment something touched the door and was fixed in the task
layer:

- **World-anchor fix.** The task layer's `FixDoorframe` world joint previously
  had unauthored (identity) local frames. Referenced under an Isaac Lab env
  namespace, that anchor snapped the physics articulation to the world origin —
  visuals stayed put, and the origin-placed panel intersected the floor, so any
  contact exploded the hinge. The joint now authors explicit world-side frames
  at the door frame's composed pose, validated by `validate_door_task_usd`.
- **Env reset fix.** Both door envs previously wrote cfg-default root poses at
  reset, teleporting the articulation root to the env origin. Resets now only
  write hinge joint state; the world joint owns the root pose.
- Door geometry (measured): panel ~0.83 m wide x 2.0 m tall x 0.036 m thick,
  one Z-axis hinge (0–90°, zero friction/damping), handle protruding ~6.5 cm
  from the push face at door-frame y∈[0.63, 0.80], z∈[0.0, 0.09].

## Controller (2.2)

`policies/scripted/door_push.py` — a deterministic FSM
(`approach → align → pre_contact → contact → push → hold → release`), pure
numpy, no Isaac imports. All waypoints are **door/panel-frame parameters**
(`DoorPushControllerCfg`: push point at 80 % of panel width, 0.30 m below the
hinge origin to clear the handle); the emitted per-tick command is a 6-dim EE
delta in the hinge-anchored door frame (= A3). Fixed-start rollouts came first;
seeded bounded variations (`sample_variation`: start offset, push radius/height)
were added after fixed-start passed and stay off by default.

Execution: `AlexDoor-DoorPush-Proxy-v0` (`envs/door_task/door_push_env.py`), a
dynamic **gravity-free proxy sphere** (`proxy_ee_sphere_v0`, r = 0.05 m, 5 kg)
driven by per-sub-step root-velocity commands equivalent to the clamped EE delta
(pos ≤ 0.02 m/tick, rot ≤ 0.05 rad/tick at control_dt = 1/60 s). A kinematic body
was rejected: kinematic-target pose writes sweep the body through the scene at
teleport speed and destabilize the articulation.

## Limitations / placeholders (explicit)

1. **Proxy end-effector, not Alex.** The A2-shaped EE-delta interface is the
   contract a later Alex adapter must implement; rotation components are
   accepted but physically inert for the sphere.
2. **A1 export placeholder** (no joints on the proxy).
3. **Contact is geometric inference** (`source: "inferred_geometric"`), not force
   sensing; the frictionless door coasts ahead of the pusher, so contact flags
   are brief (0–1 ticks per episode in the reference run).
4. **Door frame is read from the USD stage at reset** (valid: the frame is
   world-fixed and drift-checked); live articulation pose reads
   (`body_pos_w`/`root_pos_w`) return zeros in this Isaac Lab build
   (release/3.0.0-beta2).
5. **Determinism is per rendering mode**: headless and `--enable_cameras` runs of
   the same seed each reproduce exactly, but differ from each other.
6. Hinge friction/damping are zero (source asset): after release, an open door
   keeps coasting until the 90° limit stops it.
