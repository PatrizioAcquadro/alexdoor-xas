# TASK: Unified Phase 3 scientific evaluation report

> Historical path note: this prompt retains its original filename to preserve
> local references. It defines the descriptive **Unified Phase 3 scientific
> evaluation** milestone, not a second meaning of “Phase 3.4.”

Before doing anything, read `PROJECT_GUIDELINES.md` from the repo root. If it is not present, read `docs/PROJECT_GUIDELINES.md`. Treat it as binding project guidance.

This task happens only after:

1. the local post-Phase 3.3 stabilization task has passed and been committed;
2. the cluster dataset-scale training/evaluation sweep has completed or has a documented partial-failure artifact set.

Do not start Phase 4, VLA, RL, WAM-lite, hardware-transfer work, new dataset generation, new policy training, or new rollout evaluation unless the only purpose is to repair a clearly missing Phase 3 artifact and the repair is explicitly reported.

The goal is to produce the unified Phase 3 scientific report from the local and cluster artifacts. This is the first task that may compare A2 vs A3 and ACT vs Diffusion, but only within the evidence boundaries of the completed Phase 3 artifacts.

Use robotics workflows and subagents where useful:

- one subagent for artifact completeness and provenance review;
- one subagent for metric/schema normalization review;
- one subagent for statistical and matched-seed comparison review;
- one subagent for robotics safety/contact/failure-mode review;
- one subagent for final claims/readiness review.

## Scope

In scope:

- summarize local stabilization evidence;
- summarize cluster dataset-size sweep evidence;
- compare A2 vs A3 under matched data, seeds, task variation, and evaluation protocol;
- compare ACT vs Diffusion under matched data, seeds, task variation, and evaluation protocol;
- analyze dataset-size trends across 50/100/250/500 episodes where artifacts exist;
- analyze contact quality, adapter safety behavior, failure modes, and Diffusion sampler/horizon diagnostics;
- decide which Phase 3 artifacts are strong enough to carry forward into Phase 4 planning.

Out of scope:

- no VLA training or VLA-readiness claim;
- no A4 result claim;
- no WAM-lite, RL, hardware, fake-door, or sim-to-real claim;
- no geometry, viewpoint, or language generalization claim unless those axes were explicitly varied and logged in the completed artifacts;
- no new full sweep.

If an expected artifact is missing, first determine whether the report can still make a bounded claim. Do not infer missing metrics from aggregate summaries when per-rollout data is required for a matched comparison.

## Scientific Comparisons

Report primary comparisons only from complete matched primary runs.

Required comparisons:

1. A3 vs A2 within each policy and dataset size.
2. Diffusion vs ACT within each action space and dataset size.
3. Dataset-size trends for each policy/action-space pair across 50/100/250/500 episodes.
4. Safety/contact/failure-mode differences across policy/action-space pairs.
5. Diffusion sampler/horizon diagnostics, clearly separated from the primary matrix.

For success rates:

- report counts and rates;
- report uncertainty intervals, preferably Wilson/binomial intervals;
- when seeds are matched, also report paired seed-level differences where possible.

For continuous metrics such as final angle, ticks, contact force, warning counts, and adapter corrections:

- report mean, median, standard deviation, min/max, and sample count;
- report bootstrap confidence intervals or matched-seed confidence intervals where practical;
- identify outlier seeds and failure labels instead of hiding them.

For dataset-size trends:

- do not claim monotonic improvement unless the evidence supports it across matched evaluation protocols;
- distinguish training-data-size effects from sampler/horizon, dataset-quality, or seed-composition effects.

## Claims Policy

Use cautious language:

- acceptable: "In this Phase 3 sweep, under matched door-pose/orientation variation, A3 had higher/lower/similar success than A2 for policy X at dataset size Y."
- acceptable: "This suggests A3 should or should not be prioritized for Phase 4 under the current door-pose/orientation benchmark."
- acceptable: "The evidence is inconclusive because intervals overlap, artifacts are incomplete, or failures concentrate in specific seeds."

Not allowed:

- "A3 proves object-relative representations generalize better" unless the evidence includes the relevant generalization axes;
- "Diffusion is better than ACT" without matching dataset, seeds, eval protocol, and sampler/horizon metadata;
- "This is ready for VLA" as a performance conclusion;
- "This proves sim-to-real transfer";
- "A4 is validated";
- any claim about door geometry, viewpoint, language, hardware, fake-door, WAM-lite, or VLA unless those artifacts were actually generated in the relevant phase.

The final report must explicitly separate:

- confirmed repo/artifact facts;
- bounded Phase 3 findings;
- inconclusive or failed evidence;
- recommendations for Phase 4 planning.

## Stop Conditions

Stop and report instead of producing a scientific comparison if:

- required local or cluster artifacts are missing and cannot be reconstructed from logged outputs;
- A2 and A3 are still numerically identical under the supposedly varied door poses;
- matched A2/A3 or ACT/Diffusion comparisons use different seeds, thresholds, max ticks, adapter paths, observation presets, or door-variation plans;
- per-rollout seed-level data is unavailable for primary comparisons;
- dataset fingerprints, split ids, or norm-stats ids are missing;
- adapter warnings/corrections/rejections were hidden or only aggregate counts are available where warning types matter;
- Diffusion sampler/horizon metadata is missing or mixed inside the primary comparison matrix;
- force/contact metrics are expected from the Alex env but absent without explanation;
- W&B online artifacts are unavailable and no offline/local artifact path preserves the evidence.

If a stop condition affects only part of the matrix, exclude that part and continue only with explicitly bounded claims for the complete subset.
