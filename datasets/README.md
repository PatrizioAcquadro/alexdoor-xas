# datasets/

Machine-local episode datasets generated by the scripted data engine. Everything
in this directory except this README is ignored by Git.

## Active dataset

The current dataset follows this path contract:

```text
datasets/<task>/<action_space>/<version>/
```

For the active benchmark:

- `door_push_alex_v2` identifies the door-pushing task with Alex V2;
- `A1_joint_delta` through `A4_obj_centric_chunk` identify the action representation;
- `v2_pose` identifies the current dataset version with matched D0-D4 door poses.

The `v2` in `v2_pose` is the dataset version; it does not identify the robot.

```text
datasets/door_push_alex_v2/
├── A1_joint_delta/v2_pose/
├── A2_ee_delta/v2_pose/
├── A3_obj_rel_ee_delta/v2_pose/
├── A4_obj_centric_chunk/v2_pose/
└── splits/v2_pose.json
```

The four exports represent the same physical episodes and share episode IDs.
`splits/v2_pose.json` assigns those IDs to disjoint `train`, `val`, and `test`
sets for matched comparisons.

## Action representations and storage

- A1 stores joint-target deltas in HDF5 and is retained for export and interface
  verification.
- A2 stores world-frame end-effector deltas in HDF5 and is used by ACT and
  Diffusion.
- A3 stores equivalent door-frame end-effector deltas in HDF5 and is used by ACT
  and Diffusion.
- A4 stores structured object-centric chunks in `episodes.jsonl`; it supports the
  adapter path but has no learned policy.

A1-A3 contain one `episode_<id8>.hdf5` file and one
`episode_<id8>.meta.json` sidecar per episode, plus dataset metadata and
train-only `norm_stats.json`. A4 contains `episodes.jsonl` and dataset metadata.

A dataset version is one generation pass. Re-exporting creates new episode IDs,
so its split and normalization artifacts must be regenerated together.

## Generate and verify

Generate matched A1-A4 exports:

```bash
PYTHONPATH=$PWD /home/pacquadr/IsaacLab/isaaclab.sh -p \
  scripts/run_scripted_baseline.py --viz none --device cuda:0
```

Verify the dataset interface without rewriting official artifacts:

```bash
PYTHONPATH=$PWD /home/pacquadr/IsaacLab/isaaclab.sh -p \
  scripts/verify_dataset_interface.py
```

Use `src/alexdoor_xas/dataset/` to access datasets; model code must not read raw
HDF5 keys directly. See
[Episode and Dataset Contracts](../knowledge/wiki/topics/episode-and-dataset-contracts.md)
for the complete contract.
