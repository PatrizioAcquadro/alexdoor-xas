# datasets/

Reusable episode datasets generated by the scripted data engine and consumed
by ACT and Diffusion. Everything here except this README is ignored by Git.

## Layout

```text
datasets/<task>/<action_space>/<version>/
    episode_<id8>.hdf5
    episode_<id8>.meta.json
    episodes.jsonl                 # A4 only
    meta.json
    norm_stats.json
    views/<view_id>/norm_stats.json
datasets/<task>/splits/<version>.json
datasets/<task>/splits/<view_id>.json
```

A version is one generation pass. Re-exporting changes episode IDs, so its
split and normalization artifacts must be regenerated. A retained view is
loaded directly from its split JSON and matching `norm_stats.json`.

Validation checks schema, action space, dimensions, finite values, disjoint
membership, content-group leakage, and direct recomputation of train-only
normalization. Existing local files may contain extra historical metadata;
loaders ignore it. New artifacts use the minimal active format.

Generate episodes with `scripts/run_scripted_baseline.py`. Consume them through
`src/alexdoor_xas/dataset/`, not by reading raw HDF5 keys from model code.
See [Episode and Dataset Contracts](../knowledge/wiki/topics/episode-and-dataset-contracts.md).
